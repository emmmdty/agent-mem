# 学习与环境准备

本章目标：**十分钟内跑通第一个例子**。所有配置都以「纯 CPU + 一个 API Key」为基准，不需要 GPU。

## 1. 硬件与算力要求

| 章节 | 最低要求 | 说明 |
| :--- | :--- | :--- |
| 第 1、2 章 | 纯 CPU，4GB 内存 | 只用标准库 + numpy |
| 第 3~5 章 | 纯 CPU，8GB 内存 | 需下载一个约 400MB 的 embedding 模型 |
| 第 6~8 章 | 纯 CPU + LLM API | 需要能调用 LLM；本地小模型亦可 |
| 第 9 章 | **单卡 ≥ 16GB 显存** | 模型编辑实验，唯一需要 GPU 的章节 |
| 第 10 章 | 纯 CPU + LLM API | 评测 harness，默认跑小规模子集 |

第 2 章有一个可选的「注意力观察」实验需要单卡（24GB 内可完成），跳过不影响后续。

## 2. Python 环境

要求 **Python 3.10+**（本书用到 `match`、`X | None` 等语法）。

### 方式一：venv（推荐，最轻）

```bash
git clone https://github.com/emmmdty/agent-mem.git
cd agent-mem

python -m venv .venv
source .venv/bin/activate          # Windows PowerShell: .venv\Scripts\Activate.ps1

pip install -e .                   # 安装主线包 minimem（核心依赖极小）
```

### 方式二：conda

```bash
conda create -n agent-mem python=3.12 -y
conda activate agent-mem
pip install -e .
```

### 按章安装依赖

本书**按章拆分依赖**，读到哪一章装哪一章，避免一开始就装几个 GB：

```bash
pip install -e ".[vector]"   # 第 3 章：sentence-transformers, modelscope
pip install -e ".[graph]"    # 第 4~5 章：networkx, kuzu
pip install -e ".[llm]"      # 第 6~8 章：openai, tiktoken
pip install -e ".[eval]"     # 第 10 章：datasets, pandas, matplotlib
pip install -e ".[dev]"      # 参与贡献：pytest, ruff

pip install -e ".[all]"      # 一次装齐（不含第 9 章的 GPU 依赖）
```

> `[vector]` 会带进 PyTorch（约 2GB）。如果你的网络能直连 HuggingFace，
> 可以改用不需要 torch 的轻量后端：`pip install -e ".[vector-onnx]"`，安装体积约 100MB。
> **国内网络通常不行**——它的模型只从 HuggingFace 拉取，见下一节。

第 9 章的依赖单独放在 `docs/chapter9/code/requirements.txt`，**建议为它单独建一个环境**——模型编辑工具链对 `torch` 和 `transformers` 版本敏感，容易和其他章节冲突。

### 国内加速

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

## 3. LLM API 配置

从第 6 章开始需要调用 LLM。本书所有代码都走 **OpenAI 兼容接口**，因此换供应商只需改两个环境变量。

复制 `.env.example` 为 `.env`（该文件已在 `.gitignore` 中，不会被提交）：

```bash
cp .env.example .env
```

填入你的配置：

```bash
# OpenAI 官方
OPENAI_API_KEY=sk-xxxxxxxx
OPENAI_BASE_URL=https://api.openai.com/v1
AGENT_MEM_MODEL=gpt-4o-mini

# 或 DeepSeek
# OPENAI_API_KEY=sk-xxxxxxxx
# OPENAI_BASE_URL=https://api.deepseek.com/v1
# AGENT_MEM_MODEL=deepseek-chat

# 或通义千问（阿里云百炼）
# OPENAI_API_KEY=sk-xxxxxxxx
# OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
# AGENT_MEM_MODEL=qwen-plus

# 或本地 Ollama
# OPENAI_API_KEY=ollama
# OPENAI_BASE_URL=http://localhost:11434/v1
# AGENT_MEM_MODEL=qwen2.5:7b
```

验证配置是否可用：

```bash
python -m minimem.utils.check_env
```

这个脚本会检查：Python 版本、已安装的可选依赖、API 连通性、embedding 模型是否已缓存，并给出缺什么、装什么的提示。

> **成本提示**：本书实验刻意控制规模。按 2026 年年中的主流小模型价格，读完全书需要的 API 调用成本大致在**几元到几十元人民币**量级，取决于你是否重复运行第 6~8 章的实验。每个需要花钱的脚本，文件头都注明了预估调用次数。

## 4. Embedding 模型（从 ModelScope 下载）

第 3 章起需要一个句向量模型，默认用 `BAAI/bge-small-zh-v1.5`（约 95MB，512 维，中英文都可用，CPU 上编码一句约几毫秒）。

**本书默认从 [ModelScope](https://www.modelscope.cn/) 下载，不走 HuggingFace**——国内网络下前者通常快一到两个数量级，后者多数情况下根本连不上。

```bash
pip install -e ".[vector]"                    # 含 modelscope
python -m minimem.utils.fetch_model           # 下载到 ./models，并打印要设置的环境变量
```

命令结束时会提示你把类似下面这行加进 `.env`：

```bash
AGENT_MEM_EMBED_MODEL=./models/models/BAAI--bge-small-zh-v1.5/snapshots/master
```

看看本书都会用到哪些模型（按需下载，不必一次装齐）：

```bash
python -m minimem.utils.fetch_model --list
```

### 备选一：git lfs 手动克隆

```bash
git lfs install
git clone https://www.modelscope.cn/BAAI/bge-small-zh-v1.5.git models/bge-small-zh-v1.5
export AGENT_MEM_EMBED_MODEL=./models/bge-small-zh-v1.5
```

### 备选二：海外网络直连 HuggingFace

```bash
pip install -e ".[vector-onnx]"   # fastembed，不需要 torch，约 100MB
# 不必设置 AGENT_MEM_EMBED_MODEL，首次运行自动下载
```

### 完全离线的退路

如果暂时无法下载任何模型，`minimem` 内置了一个基于哈希的 `FakeEmbedder`，向量质量很差但接口一致，足以跑通全部流程、观察系统行为：

```bash
export AGENT_MEM_EMBED_MODEL=fake
```

第 3 章会用它做一个对照实验：**同一套检索代码，换成没有语义的向量后召回率掉多少**——顺带回答一个容易被跳过的问题：改善到底来自「换成了向量检索」这个架构，还是来自「向量真的懂语义」。

## 6. 本地预览文档站

文档站基于 docsify，纯客户端渲染，**无需构建**：

```bash
npm i -g docsify-cli
docsify serve docs
# 打开 http://localhost:3000
```

没有 Node 环境也可以用 Python 起一个静态服务器：

```bash
python -m http.server 3000 --directory docs
```

> 注意：用 `python -m http.server` 时，docsify 的部分插件（如全文搜索索引）行为与 `docsify serve` 略有差异，但阅读不受影响。

## 7. 目录结构说明

```
agent-mem/
├── docs/                     # 教程正文（docsify 站点根目录）
│   ├── index.html            #   站点配置
│   ├── _sidebar.md           #   侧边栏导航
│   ├── chapter1/
│   │   ├── 第一章 ....md      #   正文
│   │   ├── code/             #   本章可运行脚本 + requirements.txt
│   │   └── images/           #   本章插图
│   └── 附录/
├── minimem/                  # 主线项目：贯穿全书的记忆系统实现
│   ├── base.py               #   MemoryStore 抽象接口（第 1 章）
│   ├── buffer.py             #   BufferMemory（第 1 章）
│   ├── vector.py             #   VectorMemory（第 3 章）
│   ├── ...
│   ├── eval/                 #   EvalHarness（第 10 章）
│   └── utils/                #   计量、LLM 客户端、环境检查
└── tests/                    # 单元测试
```

**章节脚本 vs 主线包**的分工：`docs/chapterN/code/` 里是「读这一章时要跟着跑的实验」，写得直白、允许冗余、便于单独阅读；`minimem/` 里是「攒下来会被后续章节复用的实现」，写得工整、有测试。同一个机制常常两边都有——章节里是教学版，包里是工程版，正文会明确指出两者的差异。

## 8. 常见问题

**Q：`pip install -e .` 报错 `no module named setuptools`？**
A：`pip install --upgrade pip setuptools wheel` 后重试。

**Q：sentence-transformers 安装后首次运行卡在下载？**
A：多半是它在尝试连 HuggingFace。本书默认走 ModelScope，请先执行 `python -m minimem.utils.fetch_model`，再把打印出来的路径写进 `.env` 的 `AGENT_MEM_EMBED_MODEL`。急着往下读可以先用 `AGENT_MEM_EMBED_MODEL=fake`。

**Q：Windows 下中文文件名的章节打不开？**
A：确保 git 配置了 `git config --global core.quotepath false`，并用支持 UTF-8 的编辑器打开。

**Q：没有 API Key 能读到第几章？**
A：第 1~5 章全部实验都能离线跑通（第 3 章起用 `fake` embedder 或本地模型）。第 6 章起的自组织、反思、技能归纳本质上依赖 LLM 判断，无法用规则模拟——那时候需要一个 Key，本地 Ollama 也可以。

**Q：第 9 章没有 GPU 怎么办？**
A：跳过实验，只读正文。第 9 章的结论本身就是「参数化记忆目前不适合作为生产级长期记忆的主路线」，实验是为了让你亲眼看到它的副作用，不是为了让你用它。
