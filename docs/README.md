# agent-mem · 从零开始学 Agent 记忆

> 把「记忆」当成一个可实现、可评测、可攻击的工程系统。

这是一本面向工程实现的中文 **Agent 记忆（Agent Memory）** 教程。全书围绕一条主线：从零手写一个名为 **MiniMem** 的记忆系统，从最朴素的对话缓冲，一路长成带向量检索、图结构、双时间轴、自组织链接、分层调度、技能库和评测 harness 的完整体。

## 从哪里开始

| 你的情况 | 建议路径 |
| :--- | :--- |

## 全书结构

**第一部分 · 基础**：记忆的问题定义与最朴素的两种解法——把历史塞进上下文，或把历史检索回来。

- 第 1 章 为什么 Agent 需要记忆 —— `MemoryStore` 接口 / `BufferMemory`
- 第 2 章 上下文与长上下文记忆 —— `WindowMemory`
- 第 3 章 检索增强记忆基础 —— `VectorMemory`

**第二部分 · 结构化记忆**：当记忆之间有关系、有时间，扁平的向量库就不够用了。

- 第 4 章 结构化与图记忆 —— `GraphMemory`
- 第 5 章 时间感知与知识演化 —— `TemporalGraphMemory`

**第三部分 · 系统与自主性**：让记忆自己组织自己、自己调度自己、自己从经验里长出技能。

- 第 6 章 agentic memory 与自组织 —— `AgenticMemory`
- 第 7 章 OS 式分层记忆与调度 —— `LayeredMemory`
- 第 8 章 经验与技能记忆 —— `SkillMemory`

**第四部分 · 边界与落地**：把记忆写进权重可行吗？以及，你怎么知道你的记忆系统是好的、安全的？

- 第 9 章 参数化记忆与持续学习
- 第 10 章 评测、安全与工程落地 —— `EvalHarness`

## 全书统一的分析框架

我们采用 **表征 × 操作 × 载体** 三轴：

| 轴 | 取值 | 对应章节 |
| :--- | :--- | :--- |
| **表征** | 参数化 | 第 9 章 |
| | 上下文-非结构化 | 第 2、3 章 |
| | 上下文-结构化 | 第 4~8 章 |
| **操作** | 编码、巩固、索引、检索、更新、遗忘、压缩、反思 | 每章聚焦 1~2 种 |
| **载体** | 内存 / 文件 / 向量库 / 图库 / 关系库 / 模型权重 | 附录 B 选型对比 |

为什么不用「工作记忆 / 情景记忆 / 语义记忆 / 程序记忆」这套心理学四分法作为主骨架，见第 1 章的讨论。
