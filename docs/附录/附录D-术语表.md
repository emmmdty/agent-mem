## D.2 心理学四分法对照（重要）

这套划分在中文材料里流传极广。本书**不用它作为骨架**（理由见第 1 章 1.5 节），但你在读其他资料时一定会遇到，所以这里给出对照关系。

| 英文 | 常见中文译名 | 在实际系统里通常对应什么实现 |
| :--- | :--- | :--- |
| working memory | 工作记忆 | 当前 prompt 里的那几千个 token |
| episodic memory | 情景记忆 / 事件记忆 | 一张带时间戳的对话记录表 |
| semantic memory | 语义记忆 | 一张抽出来的事实表 |
| procedural memory | 程序记忆 / 过程记忆 | 一个存代码片段或 SOP 的文件夹 |
| consolidation | 巩固 / 固化 | 一个定时或按计数触发的抽取 prompt |

**为什么本书不用它作骨架**（第 1 章 1.5 节的三个理由）：

1. **落到代码里，这四类用的是同一套存储、同一套检索、同一套接口。** 内容差异不构成模块边界——你不会因为一张表存订单、另一张存用户，就说自己实现了「两种数据库」。
2. **最关键的「巩固」在现有系统里并不自动。** 它要么由固定规则触发（每 N 轮跑一次），要么需要显式调用一个抽取 prompt。第 8 章的 reflection 是同一个问题换了位置：**所有已发表系统的触发条件都是启发式的**。
3. **三篇主流综述本身就用三套不同的分类轴**，连「KV cache 算不算独立一类」都没有共识。

**本书的用词纪律**：描述具体实现时，把这些词替换成它实际的含义。不说「我们实现了情景记忆」，而说「我们存了带时间戳的原始消息」——前者听起来实现了一个认知过程，后者才是你要维护的那张表。

## D.3 八种操作

| 中文 | 英文 | 它回答什么问题 | 主要章节 |
| :--- | :--- | :--- | :--- |
| 编码 | encoding | 原始信息怎么变成可存的形式？ | 第 3、4 章 |
| 巩固 | consolidation | 零散记录怎么变成稳定的知识？ | 第 4、6 章 |
| 索引 | indexing | 怎么在不扫全表的情况下找到？ | 第 3、4 章 |
| 检索 | retrieval | 这一轮该取回哪几条？ | 第 3、4 章 |
| 更新 | updating | 新信息与旧记忆冲突时怎么办？ | 第 5、6 章 |

| 中文 | 英文 | 一句话定义 | 首次出现 |

| 重排 | rerank | 用交叉编码器对候选重新打分，准但无法预计算 | 第 3 章 3.7 |

| 通道门槛 | floor ratio | 丢弃分数远低于本通道 top1 的候选。**修 bug 而非调优** | 第 3 章 3.4.3、第 4 章 4.5 |

## D.9 评测

| 中文 | 英文 | 一句话定义 | 首次出现 |
| :--- | :--- | :--- | :--- |
| 召回率@k | recall@k | gold 里有多少比例出现在前 k 个结果中。**测不到顺序与噪声** | 第 3 章 3.2 |
| 准确率@k | precision@k | 召回结果里有多少比例是 gold。**唯一直接衡量噪声的指标** | 第 3 章 3.5 |
| 平均倒数排名 | MRR | 第一条正确结果排在第 r 位则得 1/r | 第 3 章 |
| 命中率 | hit rate | 只要召回任意一条 gold 就算 1。**在多跳上过于乐观** | 第 10 章 |
| 拒答 | abstention | 记忆里没有时承认不知道。**检索层结构上没有这个能力** | 第 10 章 10.7 |
| 答案键 | answer key | 基准的标准答案。⚠️ 有审计报告称 LoCoMo 存在成规模的答案键错误 | 第 10 章 10.3.2 |
| LLM 评判 | LLM-as-judge | 用 LLM 判断回答是否正确。⚠️ 对「主题相邻但答错」的回答宽松 | 第 10 章 10.3.3 |
| 分能力表 | per-capability breakdown | 按能力类型拆开的指标表。**总分掩盖的 bug 都在这里** | 第 3 章起 |

## D.10 安全与合规

| 中文 | 英文 | 一句话定义 | 首次出现 |
| :--- | :--- | :--- | :--- |
| 记忆投毒 | memory poisoning | 通过正常对话把伪造信息写进记忆，将来被检索时发作 | 第 10 章 10.8 |
| 攻击面占比 | occupancy | 投毒记忆在 top-k 里占的比例。**衡量攻击面，不是成功率** | 第 10 章 10.8.2 |
| 级联删除 | cascading delete | 删原始记忆时，向量、图边、派生事实、摘要都要一起处理 | 第 5 章 5.4、第 10 章 10.9.1 |
| 被遗忘权 | right to erasure | GDPR/个保法要求的删除权。**要求真删除，不是「不再检索」** | 第 10 章 10.9.1 |
| 机器遗忘 | machine unlearning | 从模型权重里移除特定信息。⚠️ 活跃但**远未成熟** | 第 9 章 9.4 |

## D.13 一个提醒

术语表最容易变成「查一遍就忘」的东西。本书对它的建议用法是：

**读其他资料时打开这一页做对照**，特别是 D.2 节。当你在别处读到「本系统实现了情景记忆与语义记忆的自动巩固」时，对照 D.2 就能立刻翻译成：「它存了带时间戳的消息和一张事实表，并且有一个定时触发的抽取 prompt。」
